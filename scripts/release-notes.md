| 文件 | 说明 |
| --- | --- |

### 便携版目录结构

```
AetherVPN.exe          图形界面（Go 静态链接，无需额外运行库）
core-bin\aether.exe    Aether 核心，独立进程
docs\                  项目文档
LICENSE.txt            许可与第三方声明
README.txt             使用说明
CHANGELOG.txt          版本变更记录
```

界面与核心保持分离：核心是可独立替换的进程，但通过更新包发布时二者一起
替换，以保证版本配套。两个可执行文件均为 Go 静态编译的自包含程序，
不需要额外的 DLL 或运行时文件。

### 本次更新

- **修复 MASQUE 连不上**：MasqueH3 需要约 120 秒才能选出网关，而连接超时判定
  只给它 150 秒（原本只有 MasqueH2/MIM 享受 300 秒预算），稍慢就在临门一脚被判
  失败并断开 —— 表现出来就是「MASQUE 完全无法连接」。现在 MASQUE 类统一给足 300 秒。
- **修复 Psiphon 出口下浏览器无法上网**：系统代理指向 HTTP 端口 1820，但核心在
  Psiphon 模式下只监听 SOCKS 1819、不起 HTTP 代理，导致隧道已连通却打不开任何网页。
  现已追加官方参数 `--psiphon-http`，两个端口都会正常监听。
- **传输逐一回归实测**：WireGuard、Gool、MasqueH2、MasqueH3 均以真实流量验证
  通过（能正常拿到出口 IP）
- 授权到期时间延长至 **2026-10-01**

### 已知限制

- **MASQUE-in-MASQUE (MIM)**：自动搜索网关在当前网络环境下较难选出干净端点。
  核心本身支持该传输（手动给定外层网关时实测约 15 秒即可连通），自动选路
  将在后续版本改进。
- 出口 IP 由 Cloudflare 按网络位置分配，客户端无法指定。部分 AI 服务会按地区
  封锁这类出口，属服务端策略，非客户端缺陷。

### 关于安全软件提示

本程序由 Go 语言静态编译、**未进行代码签名**，运行期间会启动本地 SOCKS5
代理、修改系统代理设置并添加防火墙规则。这类网络行为特征容易被部分安全
软件的启发式规则，以及浏览器 SmartScreen 的「不常见下载」机制误判，从而
出现风险提示。

需要说明：

- 发布包**未使用任何加壳、压缩、混淆或反检测手段**，构建脚本完全公开可查
- 请对照 `SHA256SUMS.txt` 校验文件哈希，确认一致后再运行
